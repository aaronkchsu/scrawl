# Original assets

- `explorers-mono.png`: active original four-character transparent atlas, generated with Codex's built-in image tool on October 30, 2026. Monochrome pixel-style miners with square, tall, wide, and pointed silhouettes. Generated once, then refined once to simplify the texture. Browser SVG viewports isolate each sprite; the downloaded PNG is unchanged. A stable viewer-ID hash selects a character consistently in the camp, climb, and profile. See [the exact prompts](explorers-prompts.md).
- `explorer.png`: earlier original colored cave explorer, retained as a historical asset. The active excavation UI no longer renders it or its CSS hue variations.
- `wordmark.svg`: original grid-letter EXCAVATION wordmark built as local SVG geometry for the user's monochrome/block-type direction. No external font request or copied logo.

No Blerpy image was included, traced, or supplied as an image-generation reference for the new atlas.

The initial excavation implementation reused existing art and made no generation calls. This later mascot pass used two built-in image-tool calls, not the project's API key. Those calls do not provide a dollar cost here; no total generation-cost claim is made. The project's API request allowance and usage ledger were unchanged.
